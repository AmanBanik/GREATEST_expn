# Lab Notebook — Fresh Start

This notebook intentionally contains no imported historical experiment results. Begin with the environment baseline and create records prospectively. Never backdate a record or imply an experiment ran if it did not.

- `sessions/`: dated session logs and command/output captures
- `experiments/`: protocol index, hypotheses, and per-run records
- `decisions/`: decisions and rationale
- `blog/`: claims supported by evidence
- `raw/`: immutable raw stdout/stderr, CSV outputs, and captured tool results
- `environment/`: baseline snapshots and later environment changes
