## 1. Summary of Primary Findings

1. **Large Working-Set Tier (64 MiB — Dramatic Latency Hiding):**
   - At $C=1$, dependent pointer traversal is serialized; median amortized wall-clock time was **125.7006 ns/op** (total runtime $0.2514\text{ s}$ for 2,000,000 operations).
   - As independent chains increased ($C \in \{2, 4, 8, 16\}$), median amortized wall-clock time decreased systematically:
     - $C=2$: **52.5748 ns/op** ($2.39\times$ speedup)
     - $C=4$: **25.7739 ns/op** ($4.88\times$ speedup)
     - $C=8$: **12.5576 ns/op** ($10.01\times$ speedup)
     - $C=16$: **9.2006 ns/op** (**$13.66\times$ intra-tier speedup**)
   - **Runtime Inversion:** At $C=8$, executing $8\times$ as many operations ($16{,}000{,}000$ operations) required **less** total wall-clock duration than $C=1$ ($0.2009\text{ s}$ vs. $0.2514\text{ s}$).

2. **Intermediate Tier (1 MiB) & Small Tier (32 KiB) Results:**
   - **Intermediate Tier (1 MiB):** Amortized latency decreased from **5.5253 ns/op** ($C=1$) down to **0.6669 ns/op** ($C=16$), representing an **$8.29\times$ intra-tier speedup**.
   - **Small Tier (32 KiB):** Amortized latency decreased from **1.4975 ns/op** ($C=1$) down to **0.2724 ns/op** ($C=16$) ($5.50\times$ amortized throughput scaling).
   - *Crucial Methodological Qualification:* Reported `ns/op` values represent **amortized wall-clock time per pointer operation** $(\text{elapsed seconds} \times 10^9 / \text{total operations})$. Sub-nanosecond amortized values ($0.27\text{ ns/op}$) reflect concurrent instruction dispatch across multiple superscalar load execution ports, **NOT sub-nanosecond physical memory load latency**. Furthermore, advancing all 16 chains in the small tier increased derived outer-loop step time from $1.50\text{ ns}$ to $4.36\text{ ns}$ and increased total elapsed runtime from $0.0030\text{ s}$ to $0.0087\text{ s}$ due to loop instruction overhead.

## 2. Verification Drift & Repeatability Caveat

The post-sweep verification re-tests exhibited non-negligible measurement drift relative to the primary sweep baseline:
- **Small Tier (32 KiB, $C=1$):** Primary median $1.4975\text{ ns/op}$ vs. Verification median $2.0998\text{ ns/op}$ ($\Delta = +0.6023\text{ ns/op}$, **$+40.22\%$**).
- **Large Tier (64 MiB, $C=4$):** Primary median $25.7739\text{ ns/op}$ vs. Verification median $35.3271\text{ ns/op}$ ($\Delta = +9.5532\text{ ns/op}$, **$+37.07\%$**). Speedup relative to primary $C=1$ baseline was **$3.56\times$** (versus $4.88\times$ during the primary sweep).

**Status of Root Cause:**
The execution log confirms exit code `0`, identical deterministic checksums (`1923` and `14274912`), and bit-for-bit source/binary integrity. However, the root physical cause of this drift remains **unresolved** by existing evidence. WSL2 hypervisor scheduling slices, thread preemption, host core placement (P-core vs. E-core migration on the Core i7-14650HX), and CPU frequency governor scaling are unconfirmed possibilities, not verified facts.

## 3. Methodological Limitations & Separation of Concepts

1. **Measured Observations vs. Proposed Mechanism:**
   - *Measured Observation:* Multi-chain execution reduces amortized wall-clock time per operation by up to $13.66\times$ at 64 MiB and inverts total runtime at $C=8$.
   - *Proposed Mechanism:* The out-of-order execution core discovers independent memory loads in the instruction window and overlaps multiple outstanding cache misses in hardware Line Fill Buffers (LFBs) and DRAM banks.
   - *Guardrail:* The benchmark measures only elapsed monotonic wall-clock time. It does **not** directly measure physical Line Fill Buffer occupancy, DRAM bus cycles, or cache miss counts.

2. **Absence of Hardware Performance Counters (PMU):**
   Under virtualized WSL2, the Linux PMU interface (`perf`) is unavailable. Direct hardware confirmation of LFB concurrency, LLC miss rates, and bus transactions cannot be obtained within this guest environment.

3. **Sample Size & Exploratory Status ($N=5$):**
   Five repetitions per configuration provide valuable exploratory evidence and establish gross non-parametric scaling trends. However, $N=5$ is **not sufficient to establish formal statistical significance, hypothesis rejection ($p$-values), or stable performance guarantees**. Absolute speedup figures ($13.66\times$, $4.88\times$, $3.56\times$) are empirical sample medians under specific run conditions, not invariant physical constants.
